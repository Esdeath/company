# 快照详情页设计

## 页面目标

详情页让读者先完成 30 秒扫描，再按 Markdown 章节深入阅读。页面必须明确数据日期、资料来源和内容边界。

## 路由

```text
/snapshots/:market/:ticker
/snapshots/:market/:ticker/:date
```

- 不带日期时，API 返回该公司最新已发布快照。
- 带日期时，返回指定版本。
- 非标准代码在服务端标准化后 `301` 到规范 URL。
- 撤回或不存在的快照返回 `404`，不能泄露草稿信息。

## 桌面布局

```text
┌──────────────────────────────────────────────────────┐
│ ← 返回列表                                           │
│ 腾讯控股                                             │
│ 00700 · HKEX · HK · 数据截至 2026-06-30              │
│ 一句话摘要                                            │
├──────────────────────────────────────────────────────┤
│ PE 18.2 │ PB 3.4 │ 股息率 2.1% │ 市值 ...            │
├───────────────────────────────────┬──────────────────┤
│ ● 快照结论                        │ 本页目录          │
│                                   │ 入口检验          │
│ 快照扫描轨                        │ 五步扫描          │
│ 01 入口检验                       │ 5秒心算           │
│ 02 五步扫描                       │ 五问清单          │
│ 03 5秒心算                        │ 资料来源          │
│ 04 五问清单                       │                  │
│ 05 资料来源                       │                  │
│                                   │                  │
│ Markdown 正文                     │                  │
└───────────────────────────────────┴──────────────────┘
```

正文列与目录列比例约为 `9:3`。正文阅读宽度不超过 `820px`，目录在桌面端使用 sticky 定位。

## 手机布局

```text
返回
公司名称
证券代码 · 市场 · 数据日期
摘要
核心指标横向换行
快照结论
[目录展开]
快照扫描轨
Markdown 正文
资料来源
```

手机端不固定目录，不使用横向指标表。宽表由 Markdown 渲染器放入可滚动容器，并显示可横向滑动提示。

## 页面模块

### 快照头部

必须展示：

- 公司名称。
- 证券代码、市场和交易所。
- 数据截止日 `data_as_of`。
- 生成时间 `generated_at`。
- 一句话摘要。

### 指标带

仅显示 frontmatter 中存在的指标。金额同时显示报告货币或行情货币，不允许省略币种。

### 结论条

`verdict` 只表达是否进入下一轮研究：

- `second_round`：进入第二轮研究。
- `skip`：暂不进入第二轮研究。

页面同时显示“这不是买卖建议”。不得把 verdict 改写为买入、持有或卖出。

### 快照扫描轨

五段编号固定，对应 Markdown 主章节：

1. 入口检验。
2. 五步扫描。
3. 5 秒心算。
4. 五问清单。
5. 资料来源。

扫描轨用于提示阅读进度，不替代正文目录。

### Markdown 正文

- 服务端解析 GFM 表格、列表、引用、链接和代码。
- 禁用原始 HTML。
- 所有外链添加 `rel="noopener noreferrer"`。
- 标题生成稳定锚点。
- 管理端预览和公开页面必须使用同一份安全 HTML。

### 历史版本

若同一公司存在多个已发布快照，在页尾显示日期列表。当前版本有明确选中状态。

## 事实与判断标识

页面不自动猜测句子性质。Skill 输出时应在正文中使用明确的小节或引用块：

- `事实`：财报、公告、行情和直接计算。
- `判断`：基于事实的筛选结论。
- `待验证`：缺少资料或需要进一步核查的问题。

视觉样式可以区分三类内容，但原始语义必须来自 Markdown。

## 页面状态

- 加载失败：显示返回列表和重新加载。
- 404：说明快照不存在或已撤回，不给出草稿状态。
- 数据字段缺失：隐藏单个指标，不影响正文。
- 来源链接失效：仍显示来源名称和采集日期，链接标记为可能失效。

## SEO

详情页使用 SSR，输出独立 title、description、canonical、Open Graph 和 JSON-LD。具体规则见 [SEO.md](./SEO.md)。
