# 管理端页面设计

## 页面目标

管理端只解决内容发布闭环：登录、导入、理解校验结果、预览和发布。首版不建设通用 CMS。

## 页面路由

| 路由 | 页面 | 权限 |
|---|---|---|
| `/admin/login` | 登录 | 公开 |
| `/admin/snapshots` | 快照列表和导入 | 管理员 |
| `/admin/snapshots/:id` | 审核、预览和操作 | 管理员 |

未登录访问受保护页面时跳到登录页，并保存安全的站内回跳地址。

## 登录页

```text
┌──────────────────────────────────────┐
│ 企业快照库 · 管理端                  │
│                                      │
│ 用户名 [________________________]    │
│ 密码   [________________________]    │
│                                      │
│ [登录]                               │
└──────────────────────────────────────┘
```

- 首版只有一个管理员账号。
- 不提供公开注册、找回密码和第三方登录。
- 登录失败使用统一提示，避免泄露用户名是否存在。
- 连续失败触发速率限制。

## 管理框架

桌面端左侧导航，手机端顶部栏加抽屉：

```text
企业快照库
├── 快照管理
└── 退出登录
```

首版只有一个业务模块，不显示无内容的仪表盘和统计图。

## 快照列表页

```text
┌──────────────────────────────────────────────────────┐
│ 快照管理                              [上传 Markdown]│
│ [全部] [草稿] [已发布] [已撤回]   [扫描 inbox]       │
├──────────────────────────────────────────────────────┤
│ 公司       市场  数据日期    状态    校验     操作    │
│ 腾讯控股   HK    2026-06-30  草稿    通过     审核    │
│ 贵州茅台   CN    2025-12-31  草稿    2错误    查看    │
└──────────────────────────────────────────────────────┘
```

功能：

- 拖放或选择单个 `.md` 文件上传。
- 扫描 `content/inbox/` 并显示发现数量。
- 按状态和市场筛选。
- 按公司名称、代码搜索。
- 查看校验结果和进入审核页。

手机端表格改成卡片，不通过横向滚动压缩操作按钮。

## 导入流程

```text
选择文件
→ 上传到临时目录
→ 文件安全检查
→ frontmatter 校验
→ 正文结构校验
→ 重复版本检查
→ 写入 drafts
→ 建立索引
```

结果分三类：

- 错误：阻止导入或发布，必须修复。
- 警告：允许保存草稿，发布前需要人工确认。
- 信息：说明标准化结果，如港股代码补零。

## 审核页

桌面端左右分栏，左侧元数据和校验，右侧公开页面预览：

```text
┌──────────────────────┬───────────────────────────────┐
│ 文件和状态           │ 公开页面预览                  │
│ 元数据               │                               │
│ 校验错误与警告       │ 与前台相同的安全 HTML         │
│ 来源链接             │                               │
│ 审计记录             │                               │
│                      │                               │
│ [删除草稿] [发布]    │                               │
└──────────────────────┴───────────────────────────────┘
```

手机端改为“检查、预览、记录”三个标签页，底部固定主要操作区。

### 操作规则

- 存在错误时禁用发布，并在按钮附近说明原因。
- 警告不阻止发布，但需要二次确认。
- 发布显示公司、市场和数据日期，防止点错版本。
- 撤回不删除文件，移回草稿目录并保留审计记录。
- 删除只允许草稿，需输入公司代码确认。
- 管理端不提供正文编辑器；修改内容后重新上传 Markdown。

## 安全要求

- 使用 HttpOnly、Secure、SameSite Cookie 保存会话。
- 所有写操作校验 CSRF Token。
- 管理页面添加 `noindex, nofollow`。
- 上传只接受 UTF-8 `.md`，上限 2 MiB。
- 文件名不参与最终路径计算。
- 页面不展示服务器绝对路径、异常堆栈和密钥。

## 可访问性和反馈

- 上传进度、校验完成和发布结果使用可被读屏器读取的状态区。
- 危险操作按钮不能只用红色区分。
- 对话框打开后锁定焦点，关闭后返回触发按钮。
- 任何失败都保留当前文件和输入状态，方便重试。
