# 公开首页设计

## 页面目标

首页让读者在手机上快速完成三件事：找到公司、判断快照日期、进入详情阅读。页面不展示复杂行情图和新闻流。

## 视觉方向

界面采用“研究台账”风格：浅灰画布、白色内容面板、深色正文、低饱和蓝绿色强调。数字使用等宽数字，减少财务数据横向跳动。

| Token | 值 | 用途 |
|---|---|---|
| Canvas | `#F2F5F6` | 页面背景 |
| Surface | `#FFFFFF` | 卡片和内容面板 |
| Ink | `#17212B` | 主文字 |
| Muted | `#66727D` | 辅助文字 |
| Line | `#D7DEE3` | 边框和分隔线 |
| Accent | `#155E75` | 链接、按钮和选中状态 |
| Positive | `#2F6B4F` | 通过或健康提示 |
| Caution | `#A15C16` | 需复核提示 |
| Negative | `#A33A3A` | 错误和高风险提示 |

- 中文优先使用系统无衬线字体。
- 数字启用 `font-variant-numeric: tabular-nums`。
- 卡片圆角 `8px`，按钮圆角 `6px`。
- 使用 `8px` 间距网格。
- 内容最大宽度 `1180px`。

## 信息结构

### 顶部栏

- 左侧产品名链接回首页。
- 右侧只保留“关于”，首版不放管理端入口。
- 手机端高度 `56px`，桌面端 `64px`。

### 首屏说明

- 标题说明网站用途，不使用投资收益承诺。
- 副文案明确资料来自公开财报和行情，内容用于研究记录。
- 搜索框是首屏最醒目的交互元素。

### 市场筛选

- 选项为“全部、A 股、港股”。
- 选中状态有背景色和边框，不能只依赖颜色。
- 状态同步到 URL，例如 `/?market=HK`。

### 最新快照列表

- 默认按 `data_as_of` 降序，再按发布时间降序。
- 同一公司首页只显示最新已发布快照。
- 首屏 SSR 返回 24 条，继续浏览进入分页或搜索页。

## 快照卡片

卡片字段固定，缺失财务指标时隐藏对应项，不显示 `--` 组成的空区域。

```text
公司名称    证券代码 · 市场     数据截止日
一句话摘要
核心指标，最多 3 项
扫描结论                         查看快照 →
```

必显字段：

- `company_name`
- `ticker` 和 `market`
- `data_as_of`
- `summary`
- `verdict`

可选指标：

- `pe_ttm`
- `pb`
- `dividend_yield_pct`
- `market_cap_million`

卡片整体可点击，同时保留可聚焦的“查看快照”链接。悬停效果只在支持 hover 的设备启用。

## 响应式规则

| 宽度 | 布局 |
|---|---|
| `0–767px` | 单列；页面左右间距 16px；指标自动换行 |
| `768–1199px` | 两列卡片；页面左右间距 24px |
| `1200px+` | 三列卡片；最大宽度 1180px |

手机端不使用横向滚动，不把筛选放进隐藏侧栏。

## 页面状态

### 加载

SSR 首屏不显示全页骨架。客户端切换筛选时保留旧列表，并在列表顶部显示细进度条。

### 空结果

```text
没有找到符合条件的公司
请尝试证券代码、公司简称，或清除市场筛选。
[清除筛选]
```

### 请求失败

显示短错误信息和“重新加载”按钮，不把后端异常堆栈暴露给用户。

## 可访问性

- 搜索框有可见标签或 `aria-label`。
- 筛选使用按钮组并标明当前选项。
- 卡片键盘焦点清晰。
- 正文和辅助文字达到 WCAG AA 对比度。
- `prefers-reduced-motion` 下关闭非必要动画。
