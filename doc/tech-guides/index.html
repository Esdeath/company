这个项目在做什么? 它是一个「企业研究资料库」:管理员在后台创建公司、上传研究资料(HTML 或 Markdown 文件),普通访问者在公开网站上按公司浏览和阅读这些资料。 麻雀虽小五脏俱全 —— 它有两个前端网站、一个后端服务、一个数据库,还有把它们串起来的反向代理和容器编排,正好覆盖了现代 Web 开发的完整链路。 下面的每项技术都有一篇独立文档,可以按推荐顺序读,也可以按分类跳着读。
