部署与 HTTPS — 把项目搬上公网

目标环境:阿里云 ECS 云服务器 · 一条命令:make deploy-aliyun

它是什么

部署就是把本机开发好的系统,安装到一台 24 小时开机、有公网 IP 的服务器上,让全世界都能访问。HTTPS 是加密版的 HTTP:浏览器地址栏的小锁 🔒,保证你和网站之间的通信不被窃听、不被篡改 —— 靠的是一张由权威机构签发的「数字证书」。

比喻:开发像在自家厨房试菜,部署像正式开餐厅:租店面(云服务器)、把整套设备原样搬过去(Docker 镜像)、挂招牌(域名)、办卫生许可证(HTTPS 证书 —— 有第三方担保「这家店是正主,不是山寨」)。证书还有有效期,到期要年检续期(自动续签)。

它解决什么问题

  • 让别人访问得到:你的电脑会关机、没有固定公网地址;云服务器两者都有。
  • 传输安全:没有 HTTPS,登录密码、Cookie 在网络上就是明文裸奔;并且现代浏览器会将 HTTP 网站标记为「不安全」。
  • 可重复、可回滚:部署写成脚本,每次上线动作一致,不靠人肉记步骤。

核心概念

云服务器(ECS)

租来的一台虚拟机,有公网 IP,装好 Docker 就能跑本项目的五个容器。

TLS 证书与 Let's Encrypt

HTTPS 的「身份证」。Let's Encrypt 免费签发,90 天有效,配自动续签脚本长期无忧。

两层 Nginx

宿主机 Nginx(管 HTTPS、公网入口、限流)→ 容器 edge Nginx(管内部路由分发)。各司其职。

systemd 服务与定时器

Linux 的「后台服务管家」:保证 Nginx 常驻,备份任务按时刻表自动执行。

在本项目中

方面说明
一条命令部署make deploy-aliyun 调 scripts/deploy-aliyun-ecs.sh:本地构建镜像 → 打包上传(build-ecs-image-bundle.sh)→ 服务器上加载并重启(load-ecs-image-bundle.sh)。日常更新就这一条。
生产边界宿主机 Nginx 是唯一公网入口(443 端口,HTTPS);容器全部只绑 127.0.0.1,公网直接摸不到。配置在 infra/aliyun-ecs/nginx.conf,还带按 IP 的写接口限流(防恶意刷)。
HTTPS 证书Let's Encrypt 签发,infra/aliyun-ecs/ 里有续期钩子,到期自动换新。
安全开关生产必须 SESSION_COOKIE_SECURE=true:会话 Cookie 只在 HTTPS 下发送(详见安全篇)。
数据备份systemd 定时器 company-backup.timer 定时执行 scripts/company-backup.sh,备份数据库与资料文件。
踩坑记录第一次部署的完整复盘在 doc/ALIYUN_ECS_DEPLOYMENT_RETROSPECTIVE.md,细节以 doc/DEPLOYMENT.md 为准。

与其他技术的关系
