Markdown 与渲染管线 — 本项目的「印刷车间」

渲染库:markdown-it-py 4.2 + mdit-py-plugins · 位于 rendering.py

它是什么

Markdown 是一种极简的纯文本写作格式:用 # 表示标题、**粗体**、- 列表 —— 人眼直接可读,程序又能把它渲染成排版好的 HTML 网页。本项目的研究资料就支持以 Markdown 上传,后端用 markdown-it-py 这个库负责「翻译成网页」。

比喻:Markdown 像作者的手稿 —— 只管内容,不管排版;渲染器像印刷车间 —— 拿到手稿,套上版式模板,印出精美的成品书页(HTML)。本项目的车间还有个规矩:手稿(source.md)和成品(rendered.html)都存档,以后想换新版式,拿手稿重印就行。

它解决什么问题

  • 写作门槛:让内容创作者专注写内容,不碰 HTML/CSS。
  • 展示一致性:所有 Markdown 资料经同一套模板渲染,站点风格统一。
  • 格式共存:本项目同时接受 HTML 和 Markdown 上传 —— HTML 保持原文直接展示,Markdown 渲染后展示,两者最终都进同一个阅读器。

核心概念

Markdown 语法

# 标题、**粗体**、[链接](url)、| 表格 | —— 十分钟能学完的标记语言。

渲染(render)

解析 Markdown 文本 → 生成对应 HTML。markdown-it-py 遵循 CommonMark 标准,本项目还启用了表格、脚注、任务列表插件。

展示模板

渲染出的正文会套进一层页面模板(标题、样式),模板文件在 apps/api/src/company_api/templates/。

源文件与产物分离

上传的原文永远保留:source.md(或 source.html)+ 渲染产物 rendered.html,存在文件系统 CONTENT_ROOT 下。

# 输入(Markdown)
## 财务摘要
- 营收 **120 亿**,同比 +18%

<!-- 输出(HTML) -->
<h2>财务摘要</h2>
<ul><li>营收 <strong>120 亿</strong>,同比 +18%</li></ul>

在本项目中

环节说明
上传分流library_service.py 按扩展名分流:.md 走渲染管线,.html 保持原文。Skill 生成的文件被视为可信管理员输入,系统不检查正文内容。
渲染rendering.py 调 markdown-it-py 渲染,套 templates/ 里的展示模板,样式对应 doc/templates/markdown/template.css 的设计。
落盘content_store.py 把 source.md 与 rendered.html 写进 CONTENT_ROOT;数据库只记「这份资料存在、放在哪」的索引。
阅读公开站点用一个空 sandbox 属性的 iframe 展示 HTML —— 资料里就算带脚本也无法运行、无法碰主站(详见安全篇)。
内容来源站外运行的 Skill(skills/hk-value-snapshot/)批量生成研究资料,产物按行业存放在 stocks/,再经管理端上传。

与其他技术的关系

FastAPI — 渲染发生在上传接口的处理流程里 PostgreSQL — 只存索引,正文在文件系统 安全 — sandbox iframe 隔离资料正文
