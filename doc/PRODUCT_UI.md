# 产品与界面设计

## 当前原型边界

`doc/prototype.html` 是当前已实现的唯一交互原型。它以单个本地 HTML 文件演示公开工作区、独立快照、移动端公司抽屉、管理员登录、HTML 导入与扫描、审核、发布、撤回和加载失败。原型用内存数据模拟认证与状态变化，不代表生产数据已经持久化。

生产目标采用 Nuxt 公开端、Vue/Vite 管理端和 FastAPI API。下文凡标为“原型已实现”的行为都应在迁移时保持；生产路由、服务端认证、文件事务和持久化属于“生产目标”。

## 公开工作区

- 原型已实现：桌面端左侧固定公司目录，右侧显示当前选中的 HTML；目录和阅读区组成主从工作区。
- 原型已实现：公开目录只包含状态为“已发布”的记录。草稿和已撤回记录不能通过公开入口访问。
- 原型已实现：首次进入选择第一条已发布记录。撤回当前记录后，界面选择筛选结果中的下一条已发布记录；没有可选记录时显示空状态，不回退到未发布内容。
- 生产目标：公开路由从 API 取得同一套发布状态与稳定 HTML 地址，刷新、前进和后退后恢复筛选与选择。

## 公司目录、搜索与排序

公开筛选支持公司名称、证券代码、市场、名称顺序和日期顺序。搜索先去除首尾空格；证券代码优先精确匹配，公司名称支持包含匹配。市场至少支持全部、A 股和港股。名称排序按规范化公司名升序；日期排序按数据截止日或发布时间降序，并明确当前选项。

筛选变化后必须重新校正选择：保留仍在结果集中的当前公司，否则选择第一条结果。空结果显示“没有找到公司”、清除筛选按钮和可操作建议。网络请求失败时保留原筛选条件，显示短错误信息与重试按钮，不暴露服务端堆栈。

生产列表使用游标分页。切换关键词、市场或排序时清空旧游标，返回列表时恢复滚动位置。

## HTML 阅读区

公开工作区、独立快照地址和管理员预览把同一个 `html_path` 交给统一渲染器，不复制快照正文，也不为不同入口生成不同内容。生产端将后端提供的稳定 HTML URL 映射到该路径。

渲染器创建带可读 `title` 的 iframe，并使用空权限的 `sandbox`：

```html
<iframe sandbox></iframe>
```

不得增加 `allow-scripts`、`allow-same-origin`、表单、弹窗或导航权限。加载期间显示进度提示。HTTP 或 HTTPS 环境必须同时取得同源 `HEAD` 成功和 iframe `load` 事件，才把文件标记为可用；只有其中一项成功仍保持校验中并禁止发布。`file://` 原型无法可靠执行 `HEAD`，只依赖 iframe `load` 作为本地回退。

## 独立快照地址

- 原型已实现：独立快照视图复用统一 HTML 渲染器，提供返回公司目录的操作，并维持 iframe 的确定高度链。
- 生产目标：每份已发布记录拥有稳定、可复制和可索引的独立地址。地址解析到与公开工作区及管理员预览相同的 HTML 文件。
- 不存在、已撤回或不可公开的记录返回 404。页面只说明内容不存在或已撤回，不泄露草稿状态、文件系统路径或校验详情，并提供返回目录入口。

## 移动端公司抽屉

移动端隐藏桌面公司栏，以“选择公司”按钮打开抽屉。抽屉使用 `role="dialog"` 和 `aria-modal="true"`，打开后把焦点移到关闭按钮，并把 Tab 与 Shift+Tab 锁定在抽屉内。用户可用关闭按钮、遮罩或 Escape 关闭；关闭或选择公司后，焦点返回重新渲染的“选择公司”按钮。抽屉打开时锁定页面滚动。

目录卡片、筛选和排序在抽屉内保持完整功能。移动端不依赖横向滚动完成选公司、筛选或主要操作。

## 管理端登录与框架

- 原型已实现：演示账号登录、受保护页面回跳、退出和失败提示。演示认证只存在于浏览器内存。
- 生产目标：服务端 Session 登录；未登录访问受保护地址时保存经过校验的站内回跳地址。登录失败统一显示“用户名或密码不正确”，不透露账号是否存在；连续失败触发限流。
- 首版不提供公开注册、找回密码或第三方登录。首个管理员通过运维命令初始化。
- 桌面管理端使用左侧导航；移动端使用顶部栏和可关闭抽屉。首版只显示快照管理与退出，不放空仪表盘。

## HTML 上传或目录扫描

管理员只导入或扫描 `.html` 文件，绝不接收 `.md`。上传支持选择和拖放单个文件；扫描只读取配置目录中的普通 `.html` 文件。原型已实现内置演示 HTML 与扫描结果，生产目标才读取服务器临时目录或扫描目录。

导入结果分为错误、警告和信息。错误阻止预览与发布；警告允许保存草稿，但发布前要求管理员确认；信息展示代码标准化等非阻断结果。界面显示公司、代码、市场、数据日期、页面标题、MIME 类型、文件名和校验时间，不显示服务器绝对路径。

## 审核、预览与发布

审核页提供“检查、预览、记录”三个区域。桌面端并排展示元数据/校验与 HTML 预览；移动端使用三个可键盘操作的标签页。管理员能执行重新校验、发布、撤回，以及删除符合条件的草稿。

文件不安全、结构无效或不可访问时，页面列出具体校验错误，不创建 iframe，并禁用发布按钮。重新校验期间继续禁用发布；只有完整校验和加载都成功后才恢复预览与发布。

发布、撤回和删除使用确认对话框。文案包含公司、代码和数据日期。警告不会自动消失，发布确认必须说明警告已进入记录。操作完成后通过读屏器可感知的 toast 反馈结果，并刷新公开目录和当前选择。

## 状态与错误处理

- 无效 HTML：列出结构或安全错误，不渲染 iframe，不允许发布。
- 空结果：保留搜索上下文，显示清除筛选操作；没有任何已发布记录时显示公开空状态。
- 网络失败或文件不可访问：显示短错误信息、重试入口和失败阶段；管理员记录增加阻断错误。
- 404：独立地址显示不可用说明和返回目录入口，不透露内部状态。
- 重试：保留当前文件、输入、筛选和审核位置；重新执行完整校验、HTTP `HEAD` 与 iframe 加载判定。
- toast：使用 `aria-live="polite"` 汇报登录、扫描、导入、发布、撤回、删除和重试结果。
- dialog：打开时锁定焦点并聚焦首个安全操作；Escape 或取消关闭后，把焦点还给触发按钮。确认操作重新渲染页面后，也要定位对应的新按钮恢复焦点。

## 安全边界

iframe 采用空 `sandbox`，所有入口保持相同限制。管理员页面不显示绝对文件路径、异常堆栈、Session、密钥或内部追踪信息。生产管理页面设置 `noindex, nofollow`；所有写操作依赖后端认证和 CSRF 校验。

前端不能绕过校验器拼接任意文件路径，也不能根据原始上传文件名生成发布地址。快照 HTML 不获得脚本、外部资源、表单、顶层导航或同源权限。

## 可访问性

- 页面使用 `lang="zh-CN"`、正确 viewport、语义标题和地标。
- 搜索、筛选、排序、上传和主要操作具有可见标签或可读名称；选中状态不能只依赖颜色。
- 键盘焦点清晰，正文与辅助文字达到 WCAG AA 对比度。
- 抽屉和对话框提供名称、模态语义、焦点锁定、Escape 关闭和焦点归还。
- 加载、校验和操作结果使用状态区；危险操作同时使用文案、图标或形状区分。
- `prefers-reduced-motion` 下关闭非必要动画。移动端表格改成卡片或标签页，不以压缩按钮或横向滚动代替响应式布局。

## 生产迁移原则

迁移以原型交互为验收基线，不把内存模拟误写成已有生产能力。Nuxt、Vue/Vite 和 FastAPI 实现必须保持发布可见性、筛选后选择校正、统一 HTML 渲染、空 `sandbox`、双重加载判定、错误阻断、移动抽屉和焦点恢复。

生产目标把演示账号替换为服务端 Session，把内置清单替换为 PostgreSQL 索引，把模拟上传/扫描替换为 HTML 文件接口，把内存发布状态替换为事务化状态机。MD 只留在网站外的 Skill 审计与重新生成流程，不进入任何页面交互。
