# 公开首页主从工作台设计

## 目标

把公开首页从“搜索页 + 三列公司卡片”改为公司目录与财务快照并列的研究工作台。用户在左侧选择公司，右侧立即阅读相应财务快照，不再经过独立详情页跳转。

当前公开范围只有“财务快照”一个栏目。右侧内容来自后台上传 Markdown 后生成的结构化快照数据；贵州茅台使用完整价值线快照，腾讯控股和美团暂时保留现有简版快照。

## 范围

本次包含：

- 公开首页桌面端主从布局。
- 公司搜索、市场筛选和选中状态。
- 同页切换公司财务快照。
- 手机端公司列表抽屉。
- 搜索无结果和数据切换状态。
- 键盘、焦点、滚动和响应式验收。

本次不包含：

- 产品与用户、商业模式、管理层或其他研究栏目。
- Markdown 解析器和后台上传流程的真实后端实现。
- 腾讯控股和美团的完整价值线数据补录。
- 登录、管理列表和审核发布页面改版。
- URL 深链接、收藏、用户偏好持久化或多标签阅读。

## 信息架构

公开首页由两个长期存在的区域组成：

```text
┌──────────── 320px ────────────┬────────────── 财务快照 ──────────────┐
│ 品牌与公司目录                 │ 当前公司、代码、栏目标签             │
│ 搜索与市场筛选                 │ 行情指标、结论、历史表格与检查清单   │
│ 单列公司卡片                   │                                      │
└───────────────────────────────┴──────────────────────────────────────┘
```

左栏回答“研究哪家公司”，右栏回答“这家公司的财务事实是什么”。目前右栏只提供财务快照，不展示空的栏目导航。

## 桌面端布局

### 页面框架

- 保留现有网站品牌和原型页面切换控制。
- 移除公开首页的大幅标题区、阅读顺序说明和三列卡片结果区。
- 公开内容区填满视口中除站点页头之外的可用高度。
- 左栏宽度固定为约 `320px`，右栏使用剩余空间。
- 左栏和右栏各自滚动，页面外层不承担主要长内容滚动。
- 右侧财务表仍在表格容器内部横向滚动，不能撑宽整个页面。

### 左侧公司目录

左栏从上到下包含：

1. “公司目录”标题和当前结果数量。
2. 公司名称或证券代码搜索框。
3. “全部 / A 股 / 港股”市场筛选。
4. 单列公司卡片列表。

公司卡片保留现有信息密度：

- 市场和数据日期。
- 公司名称和证券代码。
- 一句话摘要。
- PE、PB、股息率。
- 研究状态。

选中卡片通过背景、边框和左侧强调线表达，不依赖颜色作为唯一线索，并设置 `aria-current="true"`。整张卡片可点击，键盘用户可以用 Tab 聚焦并按 Enter 或 Space 选择。

### 右侧财务内容

右侧顶部增加紧凑的上下文栏，显示：

- 当前公司名称与证券代码。
- 市场。
- “财务快照”栏目标签。
- 移动端使用的“选择公司”按钮；桌面端隐藏。

上下文栏下方复用现有详情渲染器：

- `value_line` 格式渲染完整贵州茅台快照。
- `simple` 格式渲染腾讯控股和美团的五段简版快照。

切换公司时只替换右侧内容，不改变公开首页路由，也不经过中间页面。切换完成后右侧滚动位置回到顶部。

## 手机端抽屉

小于公开移动断点时，左栏从布局中移出，作为左侧抽屉存在：

- 页面默认只显示财务内容。
- 右侧上下文栏显示“选择公司”按钮。
- 点击按钮后，公司目录从左侧滑入，并显示半透明遮罩。
- 抽屉宽度使用 `min(88vw, 340px)`，不超过视口。
- 抽屉内完整保留搜索、市场筛选和公司卡片。
- 选择公司后关闭抽屉，更新右侧内容并滚动到顶部。
- 点击关闭按钮、遮罩或按 Escape 均可关闭抽屉。
- 抽屉打开时锁定背景滚动，将焦点移入抽屉并限制在抽屉内；关闭后焦点返回“选择公司”按钮。
- 抽屉动画尊重 `prefers-reduced-motion`。

390px 原型模式下，页面自身不能出现横向滚动；历史财务表继续使用局部横向滚动。

## 数据模型与数据流

公开首页读取解析后的快照对象，不在浏览器中解析 Markdown 原文。

```text
Markdown 文件
    ↓ 后台导入、解析和校验
结构化快照对象
    ├── 左栏公共字段：公司、代码、市场、日期、摘要、估值、状态
    └── 右栏格式字段：value_line 或 simple
```

左栏与右栏必须引用同一个快照对象，避免名称、日期、行情和估值字段不一致。

新增公开首页状态：

- `selectedSnapshotId`：当前公司，初始为贵州茅台。
- `companyDrawerOpen`：手机抽屉是否打开。
- 继续复用现有 `searchQuery`、`marketFilter` 和排序状态；公开首页不再需要卡片跳转动作。

页面刷新后不持久化选择，重新默认显示贵州茅台。

## 搜索和筛选规则

- 搜索匹配公司名称和证券代码。
- 市场筛选只改变左侧公司列表。
- 如果过滤后的列表仍包含当前公司，右侧内容保持不变。
- 如果当前公司被过滤掉，自动选择过滤结果中的第一家公司，并将右侧滚动到顶部。
- 如果没有结果，左栏显示“未找到公司”，右侧显示调整搜索或市场条件的说明。
- 清除条件后，若贵州茅台重新出现在结果中但已有有效选中项，不强制切回贵州茅台。
- 校验失败且未发布的记录只存在于管理端，不进入公开目录。

## 组件边界

原型仍是单个 HTML 文件，但渲染职责保持分离：

- `renderCompanyWorkspace()`：组合左右布局和空状态。
- `renderCompanyDirectory()`：搜索、筛选与公司卡片。
- `renderCompanyCard(snapshot, selected)`：单张公司卡片。
- `renderWorkspaceDetail(snapshot)`：右侧上下文栏和快照内容。
- 现有 `renderValueLineBody()` 与简版详情渲染器继续负责正文。
- 抽屉开关、筛选和公司选择通过现有事件委托处理。

渲染器只接收数据并输出界面；筛选、自动选择和焦点恢复由状态更新层负责。

## 异常与空状态

- 无匹配公司：目录显示清除条件入口，右侧不保留已被筛掉公司的内容。
- 快照不存在：右侧显示“该公司暂无可阅读的财务快照”，不渲染空表格。
- 简版快照：明确按简版内容展示，不伪造完整价值线模块。
- 解析失败草稿：继续由管理端展示错误原因，公开页不可见。
- 原型请求失败状态：继续保留现有演示入口，但在新的右侧内容区显示错误说明和重试按钮。

## 视觉方向

延续现有企业研究资料库的冷静、数据优先风格。主要变化来自信息结构，而不是新增装饰：

- 左栏使用略深于正文区的低对比背景，形成资料目录感。
- 公司卡片保持现有内容与圆角，但压缩纵向留白以适应目录浏览。
- 选中态使用现有品牌蓝绿色强调线，并增加文字状态“当前阅读”。
- 右侧保留贵州茅台价值线页面的排版、表格和证据标签。
- 动效集中在手机抽屉一次滑入/滑出，桌面切换不增加大面积过渡。

## 可访问性

- 左右区域使用清晰的 `aside`、`main` 和可访问名称。
- 公司卡片为真实按钮或具有等价键盘行为的控件。
- 选中项设置 `aria-current`。
- 抽屉使用对话框语义、`aria-modal` 和可见标题。
- 抽屉打开后实施焦点圈定，关闭后恢复触发按钮焦点。
- 遮罩不可成为唯一关闭方式。
- 所有交互保留可见焦点样式。

## 测试与验收

自动化结构测试覆盖：

1. 公开首页存在主从工作台和默认贵州茅台选择。
2. 左栏保留搜索、市场筛选和完整公司卡片字段。
3. 公司选择动作只更新当前快照，不切换公开路由。
4. 搜索和市场筛选遵守自动选择与无结果规则。
5. 贵州茅台仍渲染完整 `value_line` 模块。
6. 腾讯控股和美团仍渲染简版五段内容。
7. 手机抽屉具备打开、关闭、遮罩、Escape 和焦点恢复契约。
8. 390px 布局不会被工作台或财务表撑宽。
9. 管理端登录、列表和审核发布结构不受改动。

浏览器验收覆盖：

- 桌面端左栏和右栏独立滚动。
- 依次选择三家公司，右侧名称与内容一致。
- 筛选 A 股和港股时自动选择行为正确。
- 搜索无结果后可以清除条件恢复。
- 手机端抽屉可以通过按钮、公司选择、遮罩和 Escape 关闭。
- 抽屉打开期间背景不滚动，关闭后焦点返回按钮。
- 贵州茅台长表格、最早/最近年份按钮和目录锚点继续工作。
- 浏览器控制台无错误。

## 完成标准

用户打开公开首页后，无需进入详情路由即可在左侧选择公司、在右侧连续阅读财务快照。桌面端适合长时间对比浏览，手机端通过抽屉切换公司，并且现有贵州茅台完整快照与管理端流程没有回归。
