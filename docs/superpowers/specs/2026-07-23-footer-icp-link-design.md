# 页脚备案链接设计

## 目标

在公开站点页脚中间增加备案链接“浙ICP备17053536号-2”，点击后在新标签页打开 `https://beian.miit.gov.cn/`，同时保持现有页脚信息和响应式布局清晰可读。

## 布局

- 桌面端将页脚改为三列 Grid：左侧保留“企业研究资料库”，中间放置备案链接，右侧保留“HTML 与 Markdown 资料独立阅读”。
- 中间列按页脚容器的视觉中心对齐，不使用绝对定位，避免内容变化时重叠。
- 窄屏下三项改为单列排列；备案链接保持居中，左右两项沿用适合各自内容的对齐方式，并确保文字可换行、不产生横向滚动。

## 链接行为

- 链接文本固定为“浙ICP备17053536号-2”。
- `href` 固定为 `https://beian.miit.gov.cn/`。
- 使用 `target="_blank"` 在新标签页打开。
- 使用 `rel="noopener noreferrer"` 隔离新页面与原页面上下文。
- 样式沿用页脚的低强调文字色，提供明确的悬停和键盘焦点反馈。

## 代码范围

- 修改 `apps/web/app/app.vue` 中的公开站点页脚结构。
- 修改 `apps/web/app/assets/css/main.css` 中的页脚布局与链接样式。
- 在 `apps/web/tests/app.test.ts` 增加链接文本、地址、新标签页及安全属性的回归测试。
- 不修改 Admin、API、资料阅读器、iframe sandbox 或部署配置。

## 验证

- 先增加失败测试，确认当前页面缺少备案链接。
- 实现后运行 Web 定向测试和 `corepack pnpm --filter @company/web check`。
- 检查桌面与手机宽度下备案号居中、三项不重叠且页面无横向溢出。
