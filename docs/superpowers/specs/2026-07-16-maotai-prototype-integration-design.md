# 贵州茅台真实快照原型整合设计

日期：2026-07-16

## 目标

根据以下 Skill 输出，把贵州茅台的真实快照内容整合进现有单文件交互原型：

```text
doc/价值线_贵州茅台_企业快照版.md
doc/价值线_贵州茅台_企业快照版.html
```

输出仍为：

```text
doc/prototype.html
```

原始 Markdown 是内容依据，生成的 HTML 用于核对表格、层级和强调方式。整合过程不修改这两个输入文件。

## 范围

### 修改

- 首页贵州茅台卡片使用 Skill 输出的真实行情和财务摘要。
- 贵州茅台详情页展示完整价值线快照。
- 管理端将贵州茅台改为校验通过的已发布快照。
- 管理端预览复用与公开详情相同的贵州茅台内容。
- 增加独立的格式错误演示记录，保留错误校验流程。
- 更新自动测试和浏览器验收场景。

### 不修改

- 腾讯控股和美团的简版演示内容。
- 原型的颜色、字体和总体研究台账风格。
- 登录、上传、发布、撤回等现有操作逻辑。
- Skill 输出文件。
- `skills/` 目录。

## 渲染策略

原型保留两种快照格式：

```text
simple       现有五章节简版，供腾讯控股和美团使用
value_line   完整价值线快照，供贵州茅台使用
```

贵州茅台数据对象增加 `format: 'value_line'`。`renderSnapshot()` 根据 format 调用：

```text
renderSimpleSnapshot(snapshot)
renderValueLineSnapshot(snapshot)
```

首页卡片和管理端元数据仍读取公共字段，不需要知道详情格式。

### 3. 30 秒结论

结论区分为：

- `事实`：价格位置、估值区间、毛利率、ROE、负债率、营收和利润变化、净现比。

### 4. 五项扫描结论

原型原有“五段扫描轨”改为真实价值线判定：

1. 长期记录：记录向上但右端下蹲。
2. ROE 与杠杆：高回报，近年现金流打折。
3. 股本变化：长期稳定且略回购。
4. 利润率：高毛利平线。
5. 估值锚：低位但分母承压。

## 错误与边界

- 任何表格年份数与数据列数不一致时，自动测试失败。
- 数值保持字符串，避免格式化时丢失星号、百分号和千位分隔符。
- Skill 输出不存在的字段不补猜测值。
- 原始 HTML 与 Markdown 内容冲突时，以 Markdown 为准，并在实现说明中记录差异。
- 公开页面不加载或 iframe 嵌入生成的 HTML 文件。
