# 公开资料库单列树导航设计

## 目标

将公开站点独立的公司目录与资料目录合并为一棵“公司 → 资料”单列树，桌面端从三列收为两列，把更多宽度留给阅读器。移动端复用同一棵树和现有抽屉，不再要求用户选择公司后重新打开抽屉才能选择资料。

## 信息结构

导航只有两级：

- 一级是公司，显示公司名称、股票代码和市场。
- 二级是所选公司的资料，显示资料标题、格式和上传日期。

任何时候只展开当前公司。点击另一家公司后，旧公司立即收起，旧资料立即清空，新公司的二级区域显示加载状态；请求完成后展开新公司的资料。点击当前公司继续沿用现有行为，重新读取该公司的资料目录。

当前资料使用右侧砖红标记和深绿色文字表示。当前公司只改变文字与展开箭头，不再同时使用同样强度的红色标记，避免一级和二级状态竞争。

## 组件边界

新增 `LibraryDirectory.vue`，替代公开站点中的 `CompanyDirectory.vue` 与 `DocumentDirectory.vue`。组件负责：

- 渲染桌面树和移动抽屉。
- 管理抽屉开关、页面滚动锁定、焦点锁定与焦点恢复。
- 根据传入状态渲染公司、资料、加载和空状态。
- 发出 `select-company` 与 `select-document` 事件。

`app.vue` 继续持有公司、资料、选中项、请求代次和错误状态，继续负责 API 请求和过期响应保护。目录组件不发请求，也不复制阅读器逻辑。

删除不再使用的两个旧目录组件。此次合并不改变 API、数据类型、iframe 阅读器或内容安全边界。

## 桌面布局

在 `64rem` 及以上使用两列布局：固定但可收缩的目录列和 `minmax(0, 1fr)` 阅读列。目录列目标宽度约 `17rem`，保持 sticky 行为和视口内滚动；阅读器占据其余宽度。

树顶部统一显示“Research library / 公司与资料”。公司行使用展开箭头表示层级。二级资料列表向右缩进，并用细竖线连接，保持现有克制的编辑风格，不增加卡片或浮动容器。

在 `48rem` 到 `64rem` 之间继续使用移动式入口，不保留占据整列的桌面目录，避免中等宽度下阅读区被压缩。

## 移动交互

移动端保留现有抽屉的 `role="dialog"`、`aria-modal="true"`、焦点锁定、Escape、关闭按钮、遮罩关闭和 body 滚动恢复。

点击公司时抽屉保持打开，焦点留在该公司按钮，二级区域显示加载状态或资料列表。点击资料后关闭抽屉、恢复焦点到触发按钮，并在阅读器中打开所选资料。

抽屉触发按钮显示“当前公司 · 当前资料”。没有资料时只显示当前公司；没有公司时显示“浏览目录”。长文本使用省略号，不能改变按钮稳定高度或造成横向滚动。

## 状态与错误

- 公司加载时显示“正在读取公司目录…”。
- 公司列表为空时显示“暂无公司”。
- 资料加载时在当前公司的二级区域显示“资料目录读取中…”。
- 当前公司没有资料时在二级区域显示“暂无资料”。
- 公司或资料请求失败仍由现有阅读区错误状态和重试动作处理；目录保留可用的公司层级，不显示服务端堆栈。
- 公司切换期间不显示上一家公司的资料，过期响应不得重新写回树中。

## 可访问性

公司和资料都使用原生按钮。当前公司按钮使用 `aria-expanded` 表达展开状态；当前资料使用 `aria-current="true"`。二级列表通过嵌套列表表达层级，不伪装成 ARIA tree widget，以保留简单、可靠的键盘行为。

移动抽屉中的 Tab 与 Shift+Tab 必须覆盖关闭按钮、所有公司按钮和当前展开的资料按钮。选择资料关闭抽屉后，焦点返回入口按钮。

## 验收

- 桌面端只存在目录与阅读器两列，不再渲染独立资料栏。
- 任何时候只展开一个公司，旧资料在公司切换时立即消失。
- 移动端点击公司不关闭抽屉，点击资料才关闭并恢复焦点。
- 公司、资料加载与空状态显示在正确层级。
- 320px、768px、1024px 和 1280px 下无重叠或横向滚动，阅读器宽度较当前三列布局增加。
- 现有请求代次保护、错误重试和 sandbox iframe 行为继续通过测试。
- Web lint、类型检查、单元测试与生产构建通过。
