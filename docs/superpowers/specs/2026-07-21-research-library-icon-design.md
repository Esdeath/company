# 企业研究资料库图标设计

## 目标

为公开站点建立一套统一的纯符号品牌图标。图标同时用于浏览器 favicon、页眉品牌标志、Apple Touch Icon 和可安装应用图标，并在 16px 小尺寸下保持清楚可辨。

## 视觉方向

采用用户确认的 B1“深绿底研究透镜”方案：

- 深绿圆角方形底板沿用站点主色 `#285541`。
- 纸白色 `#fbfcfa` 的放大镜构成主轮廓，镜片内保留三条由长到短的资料线。
- 砖红色 `#b9503d` 圆点落在镜片右上方，表达研究中的重点发现。
- 图标不使用文字、字母、渐变、阴影或细碎装饰。

形态以简单几何和粗线条为主。16px favicon 可以省略镜片内的资料线，只保留放大镜轮廓与红点；24px 及以上版本保留完整结构。

## 资产

以一个可编辑 SVG 作为主源，所有位图从该源确定性生成。公开站点资产放在 `apps/web/public/`：

- `icon.svg`：可缩放主图标。
- `favicon.ico`：包含常用浏览器尺寸。
- `favicon-16x16.png` 与 `favicon-32x32.png`：浏览器标签页。
- `apple-touch-icon.png`：180x180。
- `icon-192.png` 与 `icon-512.png`：移动设备和应用清单使用。

页眉直接引用 `icon.svg`，显示尺寸为 32px，并与现有中英文品牌名称组成同一个首页链接。

## 页面接入

在 Nuxt 站点头部元数据中声明 SVG favicon、ICO fallback、16/32px PNG 和 Apple Touch Icon。增加最小 Web App Manifest，声明站点名称、短名称、主题色、背景色，以及 192px 和 512px 图标。

公开站点页眉在品牌文字前显示图标。桌面端保持现有紧凑高度；窄屏下图标固定尺寸，不挤压品牌名称或右侧说明。图标作为装饰元素，不重复朗读品牌名称。

本次不改变管理端品牌区，也不重做页面配色、字体或布局。

## 兼容与降级

现代浏览器优先使用 SVG favicon；不支持 SVG favicon 的环境使用 ICO 或 PNG。所有位图保留不透明深绿底，不依赖透明背景或浏览器标签栏颜色。

若 manifest 无法加载，浏览器标签页和普通网页访问仍通过独立 favicon 声明正常显示。

## 验收

- 16px、24px、32px、180px、192px 和 512px 下轮廓清楚，没有裁切或模糊边缘。
- favicon 在浅色和深色标签栏中都有明确边界。
- 页眉图标与品牌文字对齐，320px 宽屏幕不重叠、不溢出。
- Nuxt 生成的页面包含预期的 icon、manifest 和主题色元数据。
- Web 前端 lint、类型检查、单元测试和生产构建通过。
