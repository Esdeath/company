# 桌面端资料目录固定设计

## 目标

桌面端阅读长文章时，左侧“公司与资料”模块保持在视口内，不随文章正文离开屏幕。移动端继续使用现有抽屉，不改变文章后接评论的自然页面流。

## 方案

- 在桌面断点内将 `.library-directory-shell` 设为粘滞容器，顶部保留 `1.5rem` 间距，并限制为视口可用高度。
- 目录内容继续使用纵向自动滚动；当公司与资料列表超过可用高度时，只滚动左侧目录。
- 将页面横向溢出保护从 `overflow-x: hidden` 改为 `overflow-x: clip`，避免页面根元素成为可能干扰粘滞定位的滚动容器。
- 移除目录内层在桌面端的粘滞职责，避免外壳与内容出现重复定位。

## 响应式行为

- `>= 64rem`：左侧外壳粘滞，文章与评论按页面自然滚动。
- `< 64rem`：保留现有目录按钮、遮罩和抽屉定位，不应用桌面粘滞规则。

## 验证

- 布局测试断言桌面断点中的目录外壳具有 `position: sticky`、顶部偏移和视口高度上限。
- 布局测试断言根页面使用 `overflow-x: clip`，且目录内层仍可纵向滚动。
- 运行 Web 前端完整检查，确认 lint、类型检查、测试和生产构建通过。
