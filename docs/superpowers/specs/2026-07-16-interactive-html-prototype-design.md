# 企业快照库交互式 HTML 原型设计

日期：2026-07-16

## 目标

生成一个可直接双击打开的单文件 HTML 原型，用于评审企业快照库的公开前台和管理端交互。原型展示真实布局、响应式行为和关键操作反馈，不连接 FastAPI、数据库或文件系统。

输出文件：

```text
doc/prototype.html
```

## 组织方式

原型是一页迷你应用。页面顶部增加仅供评审使用的“原型控制台”，用于切换：

- 公开首页。
- 快照详情。
- 后台登录。
- 快照管理。
- 审核发布。
- 桌面和手机视口。

正式网站不实现原型控制台。业务页面本身仍遵守 `doc/PAGE_*.md` 的布局和行为。

## 技术边界

- 一个 HTML 文件，CSS 和 JavaScript 全部内联。
- 不加载框架、字体 CDN、网络图片或第三方脚本。
- 演示数据写在 JavaScript 常量中。
- 页面状态只保存在内存，刷新后恢复初始数据。
- 不读取本地 Markdown，不发送网络请求。
- 通过 History API 或内部状态模拟路由，不改写真实网站文件。

## 视觉系统

沿用现有“研究台账”设计：

| Token | 值 |
|---|---|
| 画布 | `#F2F5F6` |
| 内容面板 | `#FFFFFF` |
| 主文字 | `#17212B` |
| 辅助文字 | `#66727D` |
| 边线 | `#D7DEE3` |
| 主强调 | `#155E75` |
| 正向 | `#2F6B4F` |
| 警告 | `#A15C16` |
| 错误 | `#A33A3A` |

数字使用等宽数字。页面使用 8px 间距网格、8px 卡片圆角和克制的过渡动画。标志性元素是详情页的“五段快照扫描轨”，它对应真实研究顺序，不作纯装饰。

## 公开首页与搜索

初始数据包含 A 股、港股公司及多个发布状态。

可操作项：

- 输入公司名称或证券代码并搜索。
- 切换全部、A 股、港股。
- 切换数据日期、发布时间、公司名称排序。
- 点击卡片进入快照详情。
- 清空搜索条件。
- 通过原型控制台触发无结果和请求失败演示。

筛选和搜索即时更新结果数量。港股代码 `700` 能匹配 `00700`。结果卡片展示公司、市场、数据日期、摘要、最多三项指标和筛选结论。

## 快照详情

详情页展示：

- 公司名称、代码、交易所、数据截止日和生成时间。
- 核心指标带。
- “进入第二轮研究”或“暂不进入第二轮研究”结论。
- 五段快照扫描轨。
- 事实、判断和待验证内容块。
- 页面目录和历史版本。
- 资料来源及研究用途声明。

可操作项：

- 返回原来的列表状态。
- 点击目录滚动到对应章节。
- 手机端展开或收起目录。
- 切换历史版本。

## 后台登录

演示账号仅用于原型：

```text
用户名：admin
密码：demo123
```

可操作项：

- 空字段校验。
- 错误账号反馈。
- 正确登录后进入快照管理。
- 退出登录并返回登录页。

原型明确标注演示账号，避免评审者无法进入后续页面。

## 快照管理

管理列表包含草稿、已发布和已撤回数据。

可操作项：

- 按状态、市场和关键词筛选。
- 打开模拟上传面板。
- 点击文件选择区域，使用内置演示 Markdown，不读取真实文件。
- 扫描 inbox，模拟发现一个待导入文件。
- 查看校验错误数、警告数和标准化信息。
- 打开审核页面。

手机端将表格转换成卡片，操作按钮保持可点击，不使用整页横向滚动。

## 审核发布

审核页左侧展示元数据、来源和校验报告，右侧展示与公开端一致的内容预览。

可操作项：

- 在“检查、预览、记录”之间切换。
- 有错误时禁用发布，并显示具体原因。
- 有警告时允许发布，但打开二次确认对话框。
- 确认发布后更新状态并显示成功提示。
- 撤回已发布快照。
- 打开删除确认，但不对已发布内容提供删除。

## 通用交互

- Toast 用于短期成功或错误反馈。
- 对话框用于发布、撤回和删除确认。
- 空状态说明下一步操作。
- 错误状态提供“重新加载”。
- 键盘焦点清晰；Escape 关闭对话框；Tab 顺序符合视觉顺序。
- `prefers-reduced-motion` 下关闭非必要动画。
- 原型控制台提供 390px 手机宽度切换，并允许恢复自适应桌面宽度。

## 状态模型

```text
prototypeView
├── route
├── viewportMode
├── isAuthenticated
├── searchQuery
├── marketFilter
├── sortMode
├── selectedSnapshot
├── adminStatusFilter
├── validationScenario
├── dialog
└── toast
```

所有交互通过统一的 `render()` 根据状态重绘当前视图。事件采用容器级委托，避免重绘后丢失监听器。

## 错误演示

原型覆盖以下状态：

- 搜索无结果。
- 列表请求失败。
- 登录失败。
- Markdown 字段缺失导致导入失败。
- Markdown 有警告但允许发布。
- 文件自导入后发生变化导致发布冲突。

错误文案必须说明发生了什么及下一步如何处理，不展示技术堆栈。

## 验收标准

1. `doc/prototype.html` 可以通过 `file://` 直接打开。
2. 不依赖网络也能展示全部页面和交互。
3. 公开首页、详情、登录、管理列表和审核页均可从控制台进入。
4. 搜索、筛选、排序、登录、导入、校验和发布确认可操作。
5. 桌面布局和 390px 手机布局都可阅读和操作。
6. 键盘可访问主要控件和对话框。
7. 浏览器控制台没有 JavaScript 错误。
8. 原型不修改 `skills/` 和现有业务设计文档。
