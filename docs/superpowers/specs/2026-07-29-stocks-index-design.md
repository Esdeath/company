# Stocks 静态索引页设计

## 目标

在 `stocks/index.html` 提供一个可直接通过浏览器打开的股票研究资料入口。页面按行业组织现有股票 HTML，支持快速浏览、行业筛选和按公司名称或股票代码搜索。点击任意股票卡片后，浏览器导航到对应研究资料 HTML。

## 页面结构

- 顶部标题区显示“股票研究资料库”、用途说明、行业数和股票总数。
- 工具区包含一个搜索框和行业筛选按钮；“全部”默认选中。
- 内容区按行业分组，每组显示行业名称、股票数量和响应式卡片网格。
- 卡片显示公司名称、五位港股代码及进入图标，整张卡片均可点击。
- 搜索或筛选没有结果时显示空状态，并提供清除筛选操作。

## 数据与链接

- 只收录 `stocks/<行业>/*.html`，忽略 Markdown、隐藏文件、`stocks/index.html` 和没有股票 HTML 的目录。
- 从 `HK_公司名(代码).html` 解析公司名称与代码；链接使用经过 URL 编码的相对路径，确保中文、空格及括号文件名可以从本地文件协议和静态服务器打开。
- 行业按名称排序，行业内按股票代码升序排列，保证页面输出稳定。
- 页面数据静态写入 `stocks/index.html`，不依赖目录读取权限、接口或构建工具。

## 交互与视觉

- 搜索对公司名称、股票代码和行业名称做不区分大小写的即时匹配。
- 行业按钮为单选筛选；搜索与行业筛选可叠加，结果数量实时更新。
- 使用白色背景、深灰正文、绿色主强调和少量行业色标，风格紧凑、克制，适合资料库浏览。
- 网格在手机、平板和桌面分别采用 1、2、4 列；焦点、悬停和选中状态清晰可见。
- 页面使用语义化 HTML，搜索框带可访问标签，交互控件支持键盘操作，并尊重减少动态效果偏好。

## 验收

- 页面收录当前所有股票 HTML，行业数、行业小计和总数一致。
- 每个卡片链接指向一个实际存在的 HTML 文件，无遗漏、重复或失效链接。
- 搜索、行业筛选、清除筛选和空状态行为正确。
- 页面在本地文件协议下可使用，并在常见桌面与手机宽度下无横向溢出或文字遮挡。
